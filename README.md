# Financial Performance & Profitability Analytics Dashboard

A professional Power BI portfolio project designed to analyze revenue, expenses, profitability, transactions, and budget performance.

## Business Objective

The dashboard provides an executive-level view of financial performance and enables users to move from high-level KPIs into revenue/expense trends, departmental performance, regional profitability, and budget analysis.

## Dashboard Pages

### 1. Executive Financial Performance
Executive command center containing:
- Total Revenue
- Total Expenses
- Net Profit
- Profit Margin
- Budget-related KPI
- Monthly Revenue vs Expense trend
- Expense mix by category
- Expense budget vs actual
- Net profit by region
- Revenue by department
- Department, Region, and Transaction Type slicers

### 2. Financial Trends & KPIs
Detailed financial performance page containing:
- Total Revenue
- Net Profit
- Total Expenses
- Profit Margin
- Monthly revenue vs expense trend
- Revenue by department
- Expense mix by category
- Net profit by region
- Region filter

### 3. Revenue & Expense Analytics
Analytical page focused on:
- Expenses by department
- Revenue by region
- Monthly net profit vs budget variance
- Total budget
- Budget variance
- Average revenue per transaction
- Expense distribution by sub-category
- Department filter

### 4. Budget & Profitability
Budget-control and profitability analysis containing:
- Actual expenses
- Expense budget variance
- Profit margin
- Expense budget by department
- Actual expenses by department
- Profit by region
- Transactions by budget status
- Regional profitability table

## KPI Catalog

| KPI | Purpose |
|---|---|
| Total Revenue | Measures overall revenue generated |
| Total Expense | Measures total recorded expenses |
| Net Profit | Shows revenue less expenses |
| Profit Margin | Measures profitability relative to revenue |
| Total Budget | Shows planned budget |
| Budget Variance | Compares actual performance against budget |
| Expense Budget | Shows planned expense amount |
| Expense Budget Variance | Shows difference between actual expenses and budget |
| Transactions | Measures transaction volume |
| Average Revenue Transaction | Measures average revenue per transaction |
| Budget Status Transactions | Tracks transactions by budget status |

## Data Model

The report uses a financial transaction model centered on the `FinancialTransactions` table.

Key analytical fields include:
- Transaction Month
- Department
- Region
- Category
- Sub-Category
- Transaction Type
- Budget Status

## How to Open

1. Download `powerbi/Financial_Performance_Advanced.pbix`.
2. Open it with Microsoft Power BI Desktop.
3. Use the slicers to filter Department, Region, and Transaction Type.
4. Navigate through the four report pages.
5. Interact with charts to cross-filter the report.

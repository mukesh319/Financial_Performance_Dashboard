# KPI Catalog

## Core Financial KPIs

### Total Revenue
High-level measure of revenue generated across the selected reporting context.

### Total Expense
Total recorded expense amount across the selected reporting context.

### Net Profit
Core profitability measure derived from the financial model.

### Profit Margin
Profitability expressed relative to revenue.

### Total Budget
Total planned budget represented in the model.

### Budget Variance
Measures the difference between actual performance and planned budget.

### Expense Budget
Planned expense amount used for cost-control analysis.

### Expense Budget Variance
Difference between actual expenses and the corresponding expense budget.

### Transactions
Transaction-volume KPI used to understand activity level.

### Average Revenue Transaction
Average revenue generated per transaction.

### Budget Status Transactions
Transaction count segmented by budget status.

## Dimensions

The report supports analysis by:
- Department
- Region
- Category
- Sub-Category
- Transaction Type
- Transaction Month
- Budget Status

# Dashboard Guide

## Recommended Presentation Flow

**Executive Financial Performance → Financial Trends & KPIs → Revenue & Expense Analytics → Budget & Profitability**

This flow starts with the executive summary and progressively moves into diagnostic and budget-control analysis.

## Page 1 — Executive Financial Performance

Use this page for management-level review.

Questions answered:
- How much revenue was generated?
- What are total expenses and net profit?
- What is the overall profitability?
- How are expenses distributed?
- Which regions and departments contribute to financial performance?
- How do expenses compare with budget?

## Page 2 — Financial Trends & KPIs

Use this page for trend analysis.

Questions answered:
- How do revenue and expenses change over time?
- Which departments generate more revenue?
- Which regions contribute more profit?
- Which expense categories drive the cost base?

## Page 3 — Revenue & Expense Analytics

Use this page to diagnose operational performance.

Questions answered:
- Which departments have the highest expenses?
- Which regions generate revenue?
- What is the monthly budget variance?
- What is the average revenue per transaction?
- How are expenses distributed across sub-categories?

## Page 4 — Budget & Profitability

Use this page for financial control.

Questions answered:
- How much has been spent versus budget?
- Which departments have the largest expense variance?
- Which regions generate profit?
- How are transactions distributed by budget status?

## Dashboard UX Principles

- Use KPI cards for immediate executive signals.
- Use line charts for time-based trends.
- Use bars for category comparisons.
- Use donut charts only for composition.
- Use slicers for controlled exploration.
- Keep visual titles short and action-oriented.
